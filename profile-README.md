# Kenneth Gondwe Kaputula

Data science and analytics, with an emphasis on validation, reproducibility, and practical interpretation.

**[Portfolio website](https://governorkaputula.github.io/data-science-portfolio/)** · **[Code and studies](https://github.com/GovernorKaputula/data-science-portfolio)**

My portfolio studies three questions:

- **Hourly demand:** How well can a model estimate bike rentals when seasons and weather change?
- **Campaign response:** Can a contact ranking remain useful when predicted probabilities become unreliable?
- **Customer patterns:** Do spend-based segments survive resampling and outlier removal?

The work includes Python pipelines, SQL checks, saved predictions, technical study notes, and a responsive portfolio website. The tools used are pandas, NumPy, scikit-learn, Matplotlib, SQLite, and Git.

Every project uses a cited public dataset. Every headline result can be traced to a saved analytical output.

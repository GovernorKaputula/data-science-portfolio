Study 02 / Independent analysis

Ranking the next call—and checking the risk.

A campaign response study that separates ranking quality from probability reliability when the underlying response rate changes.

01 / The question

Which contacts should come first?

A limited call budget makes ranking more useful than a default yes/no threshold. This study tests whether campaign context, prior contact history, and economic indicators can concentrate observed responses near the top of a contact list.

The analysis uses the full, date-ordered bank-additional-full.csv dataset. It excludes completed-call duration and the final current-campaign contact count, which would not be available before the decision being modeled.

02 / Study design

Preserve the order. Remove the shortcut.

The first 60% of rows form the training set, the next 20% validation, and the final 20% the holdout. UCI describes this file as date ordered; precise timestamps and customer IDs are unavailable. Row boundaries therefore approximate a chronological split and cannot guarantee customer separation.

The candidates are logistic regression and two histogram gradient boosting models. Average precision on validation selects the 15-leaf booster. It is then refit on the first 80% of rows. Categorical encoding and numerical scaling are learned within the model pipeline.

Inspect feature choices and missing-value handling

Inputs: contact channel, scheduled month and weekday, previous contact history, previous campaign outcome, and five economic indicators. The value 999 in pdays means no previous contact; it is replaced by zero and paired with an explicit contact-history indicator.

Age, job, marital status, education, loan indicators, and credit-default status are excluded. This narrower feature set is a modeling choice, not evidence of fairness: the remaining fields can still carry indirect associations. Unknown categories remain explicit.

03 / The evidence

The ranking holds a signal.

At a 20% budget, the model selects 1,648 holdout contacts containing 991 observed responses. Precision is 60.1%, compared with a 30.8% response rate across the holdout.

04 / Interpretation

Useful ranking is not reliable probability.

PartitionRowsObserved response rate
Training24,7124.8%
Validation8,23811.1%
Holdout8,23830.8%

The response rate shifts sharply across the file. Holdout ROC AUC is 0.631; Brier score is 0.253, versus 0.273 for a constant predictor using the pre-holdout rate. Calibration bins show substantial underestimation.

These scores should not be presented as dependable response probabilities. The model offers a ranking signal in this historical sample; the evidence does not establish incremental conversions, return on investment, or deployment readiness.

The budget is fixed as a share of a retrospective batch, with ties resolved by source order. An operational threshold would need to be fixed using earlier data and tested on the next campaign. Exact customer identifiers, point-in-time economic releases, drift monitoring, recalibration, and a randomized targeting experiment would strengthen the study.

05 / Open the work

Reproduce the analysis.

Python 3.12, pinned analysis libraries, and a fixed random seed of 42. The first run downloads the source archive from UCI. The pipeline writes the metrics, predictions, and charts used on this page.

python -m venv .venv
# Activate .venv, then:
python -m pip install -r requirements.txt
python run.py campaign
python -m unittest discover -s tests
